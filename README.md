# Hi, I'm Pankaj 👋

I'm a solo founder building structured venture capital and startup funding data, sourced from recent funding activity.

Based in Almora, Uttarakhand, India.

---

## 🛠️ What I Build

I design and ship data products — structured Investor Lists and funding datasets, published as static discovery sites and sold as CSV/Excel downloads. Each project runs on the same lean stack: Google Sheets as the master data source, Google Apps Script for filtering and processing, Hugo for static site generation, and Gumroad for checkout and delivery.
