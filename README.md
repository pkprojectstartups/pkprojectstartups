# Hi, I'm Pankaj 👋

I'm a solo founder building structured venture capital and startup funding intelligence, sourced from recent funding activity.

Based in Almora, Uttarakhand, India.

---

## 🛠️ What I Build

I design and ship data products — structured Investor Lists and funding datasets, distributed as static discovery sites and exportable CSV/Excel downloads. Each project runs on the same lean stack: Google Sheets as the master data source, Google Apps Script for filtering and processing, Hugo for static site generation, and Gumroad for checkout and delivery.

---

## 🌐 VCList Network

**[vclistnetwork.com](https://vclistnetwork.com)** is the checkout hub for the network — a Gumroad-powered store for the full bundle and each sector-specific Investor List. Discovery happens across 11 sector sites; purchase and export happen through VCListNetwork.

11 sector sites, mapping active investors by sector, stage, and geography:

- [aivclist.com](https://aivclist.com) — AI
